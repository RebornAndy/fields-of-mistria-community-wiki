# Visual asset notes

- `wiki-background.webp` is an optimized local copy of an official gameplay
  screenshot published in the NPC Studio Fields of Mistria press kit:
  <https://www.fieldsofmistria.com/presskit>. Source image:
  <https://static.wixstatic.com/media/265122_631b67c5a2fe4da9b3cbe11be3d6829b~mv2.png>.
  Fields of Mistria artwork remains copyright NPC Studio and is used here in an
  editorial wiki context; confirm final public-use terms before deployment.
- `characters/*.webp` are original, non-likeness monogram placeholders created
  locally for this project. They do not reproduce official character artwork.
- `../og.png` is an original social card generated for this project with the
  built-in OpenAI image-generation tool. It contains no third-party logo or
  copied character likeness.
